The trained freshness_model.tflite is fetched during the GitHub Actions build from the
open-source Kayuemkhan/Freshness-Detector project and placed here automatically.
The model has 12 classes: fresh/stale apple, banana, bitter gourd, capsicum, orange, tomato.
If you want a fully offline source ZIP, place a compatible .tflite model here and name it
freshness_model.tflite.
